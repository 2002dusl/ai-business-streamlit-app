# 소비·신용 진단 상담 (Streamlit)

AI Business(2026-2) Assignment #2 제출용 Streamlit 웹앱입니다. 월 소득, 부채 상환액, 대출 잔액, 최근 연체, 카드 사용률을 차례로 물어보고 100점 기준으로 상환 구조를 정리해 줍니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

접속 비밀번호는 `pnumis` 입니다. 비밀번호를 넣기 전에는 상담 화면이 나오지 않습니다.

## 구성

- `app.py` — 화면, 대화 흐름, 진단 규칙
- `requirements.txt` — 실행에 필요한 패키지

## 동작 방식

1. 다섯 항목을 한 번에 하나씩 질문하고 `st.session_state`에 답변을 쌓습니다.
2. 답변이 끝나면 항목별 배점(30/20/30/20)으로 100점 만점 점수를 계산합니다.
3. 점수 구간에 따라 A~E 등급과 함께, 배점 대비 가장 낮은 두 항목을 기준으로 실행 순서를 제안합니다.
4. 이후 자유 질문(DTI, 연체, 카드 사용률, 대출 심사, 소득 변경 등)에는 규칙 기반으로 답합니다.

외부 API나 유료 키를 쓰지 않으므로 네트워크가 막혀 있어도 앱 자체는 그대로 동작합니다.

## 배포

Streamlit Community Cloud에서 이 저장소의 `app.py`를 엔트리 포인트로 지정하면 됩니다.
